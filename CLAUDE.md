## Карточка в хабе imf-vc

Проект показан коллегам в хабе **https://garrov.github.io/imf-vc/** — файл
`src/content/projects/meridius.yaml` в репозитории `GarroV/imf-vc`.

Изменение, которое меняет написанное в карточке, **не готово, пока карточка не
обновлена тем же заходом**: адрес продукта или демо, бот, шаги входа, для кого,
где работает, статус. Правка YAML → пуш в `main` imf-vc; там же прогоняются
проверки и деплой. Как устроена карточка — README imf-vc.

Мёртвые ссылки ловит ежедневная проверка хаба (`links.yml`), а поменявшийся адрес,
если старый ещё открывается, — нет. Он держится только на этом правиле.
