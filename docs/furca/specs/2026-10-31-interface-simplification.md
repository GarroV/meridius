# Упрощение интерфейса, 31.10.2026

Главная показывает пиццерии выбранной страны и состояние опубликованных чек-листов
на сегодня по местному времени каждой точки. Заполненные, доступные сейчас,
будущие по расписанию, не заполненные в срок и отменённые режимом смены считаются
раздельно. Неизвестный часовой пояс и ограниченная выдача обозначаются явно.
Расчёт состояния окна остаётся в `feed/today-status.ts`; главная его не дублирует.
Страна выбирается только из доступных вошедшему. Плитка открывает статистику
пиццерии с историей и подробностями. Ненастроенные пиццерии показываются спокойно,
без красной тревоги. Основание — D189.

Редактор оставляет ширину формулировке: многострочные поля, раскрываемые настройки
пункта, версии и библиотека под содержимым. Enter создаёт следующий пункт,
Shift+Enter добавляет строку, Alt+стрелки переставляют пункт; вставка списка сохранена.
Статус несохранённых изменений отличен от сохранённого черновика и опубликованной
версии. При переходе по ссылке из редактора или закрытии вкладки несохранённая
правка вызывает подтверждение. Успешный ответ сохранения относится только к
отправленному снимку: правка, сделанная во время запроса, остаётся несохранённой.

Подробные пояснения разделов и привязки планшета раскрываются по запросу.
Из карточки станции можно открыть прикреплённый чек-лист.

## Проверочная площадка

`deploy/review/compose.yaml` — самостоятельный стенд на MUSPELHEIM,
`C:\projects\meridius-ui-review`. База, тома и секреты отдельные; данные — `seed:demo`.
Окружение — `stand.env` вне git. Запуск из корня копии:

```powershell
docker compose --env-file stand.env -f deploy/review/compose.yaml --profile tools build
docker compose --env-file stand.env -f deploy/review/compose.yaml up -d --wait db
docker compose --env-file stand.env -f deploy/review/compose.yaml run --rm migrate
docker compose --env-file stand.env -f deploy/review/compose.yaml run --rm verify node scripts/seed-demo.mjs
docker compose --env-file stand.env -f deploy/review/compose.yaml up -d --wait app
```

Публикация только внутри tailnet: HTTPS 9037 → `127.0.0.1:8378`.
Боевой Meridius этим стендом не обновляется. Откат стенда: прежний архив исходников
и повторная сборка `app`; схема базы этим изменением не меняется. Остановка:
`docker compose --env-file stand.env -f deploy/review/compose.yaml stop app`.
