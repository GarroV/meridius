# Block: core

## Назначение

Каркас проекта: приложение Next.js, база в Docker Compose, все проверки качества и единая команда прогона. Ничего продуктового здесь нет — этот блок делает так, чтобы остальные девять строились на общем основании и не спорили о стиле.

## API-контракт

Экспортирует не код, а окружение:

- `docker-compose.yml` — PostgreSQL 17 на порту 5433, том для данных.
- `.env.example` с именами переменных: `DATABASE_URL`, `PORT`, `ADMIN_PASSWORD_HASH`, `SESSION_SECRET`.
- `scripts/check` — исполняемый, запускает формат, линт, типы, тесты с покрытием, мёртвый код, границы; пишет `reports/*.junit.xml`.
- `.githooks/pre-push`, включается `git config core.hooksPath .githooks`; падает, когда инструмента нет.
- `scripts/up` (T194): без параметров готовит стенд и держит сервер, `--no-start` доводит до
  готовности и выходит 0; неизвестный параметр — отказ. Сторож — `up-script.test.ts`.
- Порт приложения — `src/blocks/core/app-port.ts` (T163): `PORT` окружения, настроек, иначе 3100.
- Сетка каркаса кабинета — `core/ui/admin-frame.ts` (T193): `ADMIN_FRAME_CLASS` (корень) и
  `ADMIN_CONTENT_CLASS` (область содержимого). Сверху складки (`--page-fold`, 768 px) меню —
  боковая колонка 208 px, ниже — верхняя полоса, содержимому достаётся вся ширина.
  **Экран, рисующий каркас сам**, берёт класс отсюда, а не пишет литерал; сторож —
  `admin-frame.test.ts`. С D164 меню одно на всех ширинах (216 px, уже 1100 px — 56 px иконок).
- Мастер-деталь разделов (D162, D163) — `core/ui/MasterDetail.tsx`: меню, колонка списка
  18rem и рабочая зона; ставится в разметку сегмента раздела, поэтому колонка не
  перерисовывается при выборе элемента. Какой элемент открыт, каркас узнаёт по сегменту
  адреса; ниже складки показывает либо список, либо рабочую зону со ссылкой назад.
  Заголовок рабочей зоны без меню — `core/ui/AdminPage.tsx` (из него же собран
  `AdminShell`). Сужение колонки в адресе без перехода Next и без сброса на адресах без
  параметров — `core/ui/use-sticky-query.ts`.
- **Главная кабинета** (`/admin`, T315, D148) — работа вошедшего, а не указатель
  разделов. Разметка — `core/ui/AdminHome.tsx`: получает готовые строки и адреса, в базу и
  чужие блоки не ходит (границы модулей). Собирает её `src/app/admin/page.tsx` из тех же
  функций, что и разделы, с областью видимости вошедшего (D145): чек-листы —
  `editor/listing.listChecklists` (шаблонов нет, D149), дырки — `stations/overview.countGaps`
  (ссылка — `?gap=noChecklist` раздела «Станции»), заполнения — `data.listSubmissions` со
  странами зрителя. Нет чек-листов — только `StatusCard` с действием «Сделать из шаблона».
  Строки — пространство словаря `adminHome` (серверное, на клиент не уходит). Сторож
  области — `/admin` в PROBES `e2e/tenant-scope.spec.ts` (своё видно, чужое нет).
- **Вводный блок раздела** (D152, T316) — `core/ui/SectionIntro.tsx`, серверный, словарь
  `sectionIntro.<раздел>.{why,what,next}` на обоих языках. Какие разделы обязаны —
  `core/section-intro.ts` (меню без уводящих в «Станции»). Экран раздела ставит
  `<SectionIntro section="…" />` первым в содержимом; раздел мастер-детали отдаёт его ещё и
  каркасу (`MasterDetail`, проп `intro`) — ниже складки он стоит над колонкой. До 640 px
  включительно видна первая строка, остальные две — под «Подробнее» (`<details>`,
  `sectionIntro.more`, D172). Сторожа: `section-intro.test.ts` (словари и вставка) и
  `e2e/section-intro.spec.ts` (1280 — целиком, 375 — первая строка и раскрытие; ru и en).
- **Экраны отказа — общие и заводятся ЗДЕСЬ**, а не каждым блоком заново:
  `src/app/error.tsx` (не собрался экран публичной стороны), `src/app/global-error.tsx`
  (не собралась сама разметка), `src/app/not-found.tsx` (адреса нет, публичная сторона),
  `src/app/admin/error.tsx` (не собрался экран кабинета) и `src/app/admin/not-found.tsx`
  (адреса нет в кабинете). Оба кабинетных стоят внутри каркаса и охраны.
- **Вид состояния выбирает поверхность, а не блок** (T213-T215): сотрудническая —
  `core/ui/StateScreen.tsx` (полный экран, одно действие `STATE_ACTION_CLASS`), кабинетная —
  `core/ui/StatusCard.tsx` внутри `AdminShell` (`STATUS_ACTION_CLASS`). Сторож —
  `failure-screens.test.ts`; отказ окрашен отдельно от пустого состояния.
- Клиентской стороне словарь отдаётся разделами, а не целиком (иначе 28 КБ на каждую
  страницу, включая кухонный телефон): корневая разметка отдаёт `failure`, разметка
  кабинета — `failure` и `admin` (их просит граница ошибки кабинета, рисующая меню).
- Язык документа равен языку содержимого уже в ОТДАННОМ документе (T270): корневая
  разметка объявляет язык запроса, на публичном экране заполнения — решение
  `blocks/fill/document.ts`. Клиентского рубежа нет (`HtmlLangSync` снят в T272, D125).
  Сторожа — по отданному ответу: `e2e/page-lang.spec.ts`, `e2e/brand.spec.ts` (T271).
- **Тема — атрибут `data-theme` на `<html>`, и больше ничего** (T236, D106). Значения — только
  в эталоне (D013). Ставят корневая разметка из куки `meridius_theme` и инлайновый скрипт
  из `prefers-color-scheme`, когда выбора нет. Механизм — `core/theme.ts`, переключатель —
  `core/ui/ThemeToggle.tsx` (слова ему отдаёт меню готовыми, T254), `ThemeProvider.tsx`.
  Сторожа: `e2e/theme.spec.ts` и `design-reference.test.ts` (токены без тёмного значения,
  цвет мимо токенов — по исходникам, а не по собранному CSS).
- **Кольцо фокуса на акцентной заливке — одно правило** (T280): `globals.css`, слой
  `components`, крючок `.bg-accent`, `--focus-ring` через `box-shadow`. Сторожа:
  `e2e/focus-ring.spec.ts` и `design-reference.test.ts`.

## Definition of Done блока

1. `docker compose up -d` поднимает базу, `psql "$DATABASE_URL" -c 'select 1'` отвечает.
2. `npm run dev` отдаёт страницу на порту копии (умолчание 3100), и `npm run start` — на нём же.
3. `scripts/check` проходит на пустом проекте и пишет отчёт в `reports/`.
4. Каждая из шести проверок **проверена на испорченной копии**: неформатированный файл, нарушение правила линта, ошибка типов, падающий тест, неиспользуемый экспорт, импорт мимо графа — каждая падает и печатает внятную причину.
5. `.npmrc` содержит `min-release-age=7`.
6. Смоук Tailwind 4 с токеном из `@theme inline` на реальной странице — цвет применился.
7. Смоук next-intl: язык страницы меняется по заголовку браузера, а в кабинете его перебивает выбор человека из куки (D144).
8. Хук `pre-push` останавливает пуш при красной проверке (проверено намеренной поломкой).

## Осознанные ограничения — проверено, а не забыто

- `global-error.tsx` — только английский (язык вычисляет упавшая разметка) и живьём не
  проверялся: проверена форма файла.
- Экран отказа при недоступной базе проверен только живым запуском, не прогоном.
- Без JavaScript язык документа — язык запроса, автоматика темы не работает (явный выбор — да).
- Переключатель темы — только в кабинете; нужен ли он на кухне — вопрос владельцу.
