# Block: core

## Назначение

Каркас проекта: приложение Next.js, база в Docker Compose, все проверки качества и единая команда прогона. Ничего продуктового здесь нет — этот блок делает так, чтобы остальные девять строились на общем основании и не спорили о стиле.

## API-контракт

Экспортирует не код, а окружение:

- `docker-compose.yml` — PostgreSQL 17 на порту 5433, том для данных.
- `.env.example` с именами переменных: `DATABASE_URL`, `PORT`, `ADMIN_PASSWORD_HASH`, `SESSION_SECRET`.
- `scripts/check` — исполняемый, запускает формат, линт, типы, тесты с покрытием, мёртвый код, границы; пишет `reports/*.junit.xml`.
- `.githooks/pre-push`, включается `git config core.hooksPath .githooks`; падает, когда инструмента нет.
- `scripts/up` (T194): без параметров готовит стенд и держит сервер, `--no-start` доводит до
  готовности и выходит 0; неизвестный параметр — отказ. Сторож — `up-script.test.ts`.
- Порт приложения — `src/blocks/core/app-port.ts` (T163): `PORT` окружения, настроек, иначе 3100.
- Сетка каркаса кабинета — `core/ui/admin-frame.ts` (T193): `ADMIN_FRAME_CLASS` (корень) и
  `ADMIN_CONTENT_CLASS` (область содержимого). Сверху складки (`--page-fold`, 768 px) меню —
  боковая колонка 208 px, ниже — верхняя полоса, содержимому достаётся вся ширина.
  **Экран, рисующий каркас сам**, берёт класс отсюда, а не пишет литерал; сторож —
  `admin-frame.test.ts`. Выше складки меню — колонка ядра (216 px, уже 1100 px — 56 px
  иконок, D164), ниже — верхняя полоса во всю ширину со своей прокруткой (D092, T344):
  раскладка — `globals.css`, слой `components`; сторож — `e2e/admin-mobile.spec.ts`.
- **Меню знает роль вошедшего** (T344) — `core/ui/admin-viewer.tsx`: разметка кабинета
  отдаёт роль (`hq` | `partner`) в `AdminViewerProvider`; `HqOnly` прячет разделы
  `ADMIN_HQ_ONLY_SECTIONS` (сейчас «Партнёры»), `NavViewer` пишет роль в подвале
  (`admin.nav.roles`). Это вид, а не охрана: адрес закрывает `requireHq`. Сторож —
  `e2e/partner-cabinet.spec.ts`; крошка экрана — `data-testid="admin-crumbs"` в `AdminPage`.
- Мастер-деталь разделов (D162, D163) — `core/ui/MasterDetail.tsx`: меню, колонка списка
  18rem и рабочая зона; ставится в разметку сегмента раздела, поэтому колонка не
  перерисовывается при выборе элемента. Какой элемент открыт, каркас узнаёт по сегменту
  адреса; ниже складки показывает либо список, либо рабочую зону со ссылкой назад.
  Заголовок рабочей зоны без меню — `core/ui/AdminPage.tsx` (из него же собран
  `AdminShell`). Сужение колонки в адресе без перехода Next и без сброса на адресах без
  параметров — `core/ui/use-sticky-query.ts`.
- **Главная кабинета** (`/admin`, T315, D148) — работа вошедшего, а не указатель
  разделов. Разметка — `core/ui/AdminHome.tsx`: получает готовые строки и адреса, в базу и

- **Вводный блок раздела** (D152, T316) — `core/ui/SectionIntro.tsx`, серверный, словарь

## Definition of Done блока

1. `docker compose up -d` поднимает базу, `psql "$DATABASE_URL" -c 'select 1'` отвечает.
2. `npm run dev` отдаёт страницу на порту копии (умолчание 3100), и `npm run start` — на нём же.
3. `scripts/check` проходит на пустом проекте и пишет отчёт в `reports/`.
4. Каждая из шести проверок **проверена на испорченной копии**: неформатированный файл, нарушение правила линта, ошибка типов, падающий тест, неиспользуемый экспорт, импорт мимо графа — каждая падает и печатает внятную причину.
5. `.npmrc` содержит `min-release-age=7`.
6. Смоук Tailwind 4 с токеном из `@theme inline` на реальной странице — цвет применился.
7. Смоук next-intl: язык страницы меняется по заголовку браузера, а в кабинете его перебивает выбор человека из куки (D144).
8. Хук `pre-push` останавливает пуш при красной проверке (проверено намеренной поломкой).

## Осознанные ограничения — проверено, а не забыто

- `global-error.tsx` — только английский и живьём не проверялся: проверена форма файла.
- Экран отказа при недоступной базе проверен только живым запуском, не прогоном.
- Без JavaScript язык документа — язык запроса, автоматика темы не работает (явный выбор — да).
- Переключатель темы — только в кабинете; нужен ли он на кухне — вопрос владельцу.
