# Block: core

## Назначение

Каркас проекта: приложение Next.js, база в Docker Compose, все проверки качества и единая команда прогона. Ничего продуктового здесь нет — этот блок делает так, чтобы остальные девять строились на общем основании и не спорили о стиле.

## API-контракт

Экспортирует не код, а окружение:

- `docker-compose.yml` — PostgreSQL 17 на порту 5433, том для данных.
- `.env.example` с именами переменных: `DATABASE_URL`, `PORT`, `ADMIN_PASSWORD_HASH`, `SESSION_SECRET`.
- `scripts/check` — исполняемый, запускает формат, линт, типы, тесты с покрытием, мёртвый код, границы; пишет `reports/*.junit.xml`.
- `.githooks/pre-push`, включается `git config core.hooksPath .githooks`; падает, когда инструмента нет.
- `scripts/up` — два режима и один список шагов (T194). `./scripts/up` готовит стенд и
  запускает сервер (foreground, Ctrl-C); `./scripts/up --no-start` доводит стенд до
  той же готовности (база, миграции, демонстрационный контур, сборка) и выходит кодом 0 —
  это то, что зовёт всякий неинтерактивный прогон: CI, приёмка блока, сквозной смок.
  Неизвестный параметр — отказ до любого действия. Сторож — `up-script.test.ts`.
- Приложение поднимается на порту из настроек копии (`PORT` в окружении, затем в
  настройках, затем умолчание 3100) — одинаково для `npm run dev`, `npm run start`
  и `./scripts/up`; источник один, `src/blocks/core/app-port.ts` (T163). Тот же источник
  спрашивают сквозной смоук и заведение пакета чек-листов (T190).
- Сетка каркаса кабинета — `core/ui/admin-frame.ts` (T193): `ADMIN_FRAME_CLASS` (корень) и
  `ADMIN_CONTENT_CLASS` (область содержимого). Сверху складки (`--page-fold`, 768 px) меню —
  боковая колонка 208 px, ниже — верхняя полоса, содержимому достаётся вся ширина.
  **Экран, рисующий каркас сам** (сегодня такой один — редактор), берёт класс отсюда, а не
  пишет литерал; сторож — `admin-frame.test.ts`.
- Экраны отказа — общие и заводятся ЗДЕСЬ, а не каждым блоком заново: `src/app/error.tsx`
  (не собрался экран), `src/app/global-error.tsx` (не собралась сама разметка),
  `src/app/not-found.tsx` (адреса нет, публичная сторона) и `src/app/admin/not-found.tsx`
  (адреса нет в кабинете, внутри каркаса и охраны). Карточка состояния для них —
  `core/ui/StatusCard.tsx`; блоку, которому нужен свой экран состояния, брать её оттуда.
- Язык документа равен языку содержимого: корневая разметка объявляет язык запроса, а
  `core/ui/HtmlLangSync.tsx` подтягивает его к языку, который экран объявил на своём корне
  (`<div lang=…>` у экрана заполнения). Экран, говорящий не на языке запроса, обязан
  объявить свой язык на КОРНЕ своего содержимого — иначе документ останется с чужим.
- `scripts/test-count-gate.mjs` + `test-count-baseline.json` — планка числа ВЫПОЛНЕННЫХ
  проверок (T225, D101). Число лежит в репозитории рядом с конфигурацией раннеров,
  читается из `reports/*.junit.xml` и краснеет, когда выполнено меньше, даже если ни
  один тест не упал. Пропуск считается падением; законен только объявленный поимённо
  в `allowedSkips`. Планка двигается вверх командой `--update` после принятой приёмки —
  как база покрытия. Логика: `src/blocks/core/test-count-gate.ts`.
- **Цели прогона — один список и один набор переменных** (T226, D101): `scripts/check`
  зовёт `npm run test` и `npm run e2e`, флаги живут в `package.json` в единственном
  экземпляре, хук `pre-push` и CI зовут ту же `scripts/check`. Переменных ни одна цель
  себе не приписывает — все читают окружение копии и `.env` одинаково. Сторож —
  `src/blocks/core/run-targets.test.ts`; он же краснеет, когда цель осталась без планки.

## Definition of Done блока

1. `docker compose up -d` поднимает базу, `psql "$DATABASE_URL" -c 'select 1'` отвечает.
2. `npm run dev` отдаёт страницу на порту копии (умолчание 3100), и `npm run start` — на нём же.
3. `scripts/check` проходит на пустом проекте и пишет отчёт в `reports/`.
4. Каждая из шести проверок **проверена на испорченной копии**: неформатированный файл, нарушение правила линта, ошибка типов, падающий тест, неиспользуемый экспорт, импорт мимо графа — каждая падает и печатает внятную причину.
5. `.npmrc` содержит `min-release-age=7`.
6. Смоук Tailwind 4 с токеном из `@theme inline` на реальной странице — цвет применился.
7. Смоук next-intl: язык страницы меняется по заголовку браузера без cookie.
8. Хук `pre-push` останавливает пуш при красной проверке (проверено намеренной поломкой).

9. Планка числа проверок краснеет на испорченном входе: убранная проверка и пропуск
   по отсутствию окружения оба дают красный прогон (проверено намеренной порчей).
